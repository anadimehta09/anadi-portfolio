# Anadi Mehta: Portfolio files

Copy these into your existing Vite + React project (replace files with the same name):

- index.html
- public/favicon.svg
- src/main.jsx, src/App.jsx, src/index.css, src/App.css
- src/components/*
- src/data/*

Then:
1. Put your resume at public/resume.pdf
2. Fill in your links in src/data/site.js and src/data/projects.js
3. Run `npm run dev`

No extra dependencies are needed (React + Vite only).
